# 第5章 train3d.py：三次元の3粒を学習し直す

第5章の勾配を、カメラへの投影を通して三次元の位置、スケール、回転まで戻すコードです。Pythonの標準ライブラリだけで動きます。

既知の3粒から同じ描画式で4視点（各32×24画素）の教師画像を作り、すべてのパラメータを教師の値からずらした3粒を、その画像とカメラだけから学習し直します。[train.py](../ch05_train/) との違いは二つです。粒が位置、スケール、回転、不透明度、色を持つ楕円体になることと、勾配が投影を通って三次元のパラメータまで戻ることです。

```sh
python3 train3d.py
```

## 本物の3DGSと違うところ

- 一回の反復で4視点すべての損失を足して勾配を求めます。反復ごとにカメラを一つ選ぶことはしません。
- 粒の個数は3個に固定し、密度制御は行いません。
- 損失は画素の差の二乗平均（MSE）です。
- 色は固定のRGBで、球面調和関数は使いません。
- 教師画像を同じ描画式で作っているので、実写で学習するときの難しさ（粒の数が足りない、姿勢がずれる、写真ごとに明るさが違う）はありません。

既知の粒との位置誤差が0.165894から0.000114へ減ったことから、粒が三次元の正しい位置へ近づいたと分かります。PSNRだけでは粒の位置が正しいとは言えませんが、この例では正解の粒が分かっているので、位置まで確かめられます。

## 関数と式

一つの粒は `[x,y,z, log sx,log sy,log sz, qw,qx,qy,qz, 不透明度のロジット, r,g,b]` の14個の値です。

| 関数 | 内容 |
| --- | --- |
| `project` | 第4章の投影。$\Sigma = RSS^\top R^\top$ を作り、$\Sigma_{\text{screen}} = JW\Sigma W^\top J^\top + 0.3I$ を求める |
| `pixel` | 一画素の合成 |
| `alpha_backward`、`composite_backward` | 色から $\alpha$ へ、$\alpha$ から画面上の位置、共分散、不透明度へ戻す |
| `project_backward` | 画面上の位置と共分散の勾配を、三次元の位置と共分散へ戻す |
| `covariance_backward`、`rotation_backward` | 三次元の共分散の勾配を、スケールとクォータニオンへ戻す |
| `check_gradients` | 起動時に、168成分（4視点×3粒×14個）の勾配を数値微分と比べる |

$W$ はカメラの回転で、第4章の $R_{\text{camera}}$ をコードの名前に合わせて書いたものです。`project` は粒を一つずつ計算し、逆伝播で使う途中の値を `cache` に入れて返します。

## 三次元の勾配の式

$G_2$ と $G_3$ を、それぞれ画面上と三次元の共分散の各成分に対する損失の勾配を並べた行列とします。$G_2$ は $\partial L/\partial \alpha$ から求まります。画素と粒の中心の差を $d$ とし、$v = \Sigma_{\text{screen}}^{-1}d$ と置くと、一つの画素の寄与は $\frac{\partial L}{\partial \alpha}\cdot\frac{\alpha}{2}\,vv^\top$ です。これを粒が掛かる画素について足します。

第 $k$ 軸のスケールの対数を $s_k$、回転行列 $R$ の第 $k$ 列を $r_k$ とすると、スケールまでの連鎖は次の二式です。

$$G_3 = W^\top J^\top G_2 J W, \qquad \frac{\partial L}{\partial s_k} = 2e^{2s_k}\,r_k^\top G_3\, r_k$$

`covariance_backward` の `dscale` の行がこの二つ目の式です。

**数値例**：粒の向きをカメラ座標の軸にそろえ、中心を光軸上に置きます。焦点距離が26画素、奥行きが2、x軸のスケールが0.1なら、画面上のx方向の分散は $(26/2 \times 0.1)^2 + 0.3 = 1.99$ 画素²です。この分散に対する損失の勾配が−0.2のとき、$G_3$ の左上は $13^2 \times (-0.2) = -33.8$ で、スケールの対数に対する勾配は $2 \times 0.1^2 \times (-33.8) = -0.676$ になります。`check_gradients` の最後の `assert` がこの値を確かめています。

**回転**：同じ $G_3$ から、まず $R$ の各成分に対する勾配（$2G_3R\,\mathrm{diag}(s_k^2)$）を求め、それをクォータニオンへ戻します。クォータニオンは使う前に長さを1にそろえるので、その計算の微分も掛けます。長さだけを変えても回転は変わらないので、長さの方向の勾配はこの微分で取り除かれます。

**位置**：色が見る方向によらない粒では、三次元の位置の勾配は二つの経路の分を足したものです。一つは投影した中心が動く分、もう一つは位置によって $J$ が変わり、画面上の楕円の形が変わる分です。`project_backward` の `dm` の式がこの二つを足しています。色を球面調和関数で表す場合は三つ目の経路が加わります。位置が動くと粒を見る方向が変わり、その方向で色が変わるからです。[元の実装の逆伝播](https://github.com/graphdeco-inria/diff-gaussian-rasterization/blob/59f5f77/cuda_rasterizer/backward.cu)は、この三つを足しています。

式の全体は[gsplatの数学補遺](https://arxiv.org/abs/2312.02121)にあります。
