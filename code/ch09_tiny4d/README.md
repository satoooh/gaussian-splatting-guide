# 第9章 ch09_tiny4d.py：3粒の4Dガウシアンを学習する

第9章の「3粒を学習して未学習の時刻を描画する」で使ったコードです。二次元の画像に時刻を足した $(x, y, t)$ のガウシアンを3粒だけ学習します。奥行きとカメラへの投影は扱いません。章の合成シーン（三次元）の実験コードではありません。Pythonの標準ライブラリだけで動きます。

```sh
python3 ch09_tiny4d.py
```

固定した場合だけを動かすには `--static` を付けます。結果は `ch09_tiny4d.static.json` に保存されます。

## 学習の設定

- 正解の動画は48×32画素、時刻0〜30の31枚で、`teacher` 関数で作ります。横0.7、縦0.1画素/フレームで動く黄色の円、時刻15の前後だけ現れる灰色の円、静止した長方形が写っています。
- 時刻0〜30の偶数16枚で学習し、奇数15枚は評価だけに使います。
- 粒は三つの形の近くに一つずつ置きます。粒の数と色は固定し、中心、広がり（縦横同じ円）、時間幅、速度、不透明度を学習します。
- 各反復で学習画像から384画素を選び、画素の二乗誤差を損失にして、Adamの学習率を徐々に下げながら600反復を回します。
- 本文の数値は、MacBook Pro（Apple M5 Max、Python 3.15.2）で実行した結果です。

## 関数と本文の式

| 関数 | 内容 |
| --- | --- |
| `teacher` | 正解の動画を作る |
| `activate` | 一粒の8個の値 [μx, μy, μt, log σ, log σt, vx, vy, 不透明度のロジット] から、断面の分散 σ²、Σtt、Σxt = vx Σtt、Σyt = vy Σtt、不透明度を作る |
| `evaluate` | 時刻で切った断面（中心 μx + Σxt/Σtt (t − μt)、分散 σ²、重み exp(−(t − μt)²/2Σtt)）を第4章と同じアルファ合成で重ね、損失と勾配を返す |

共分散は Σ = [[σ²+vx²Σtt, vx vy Σtt, vxΣtt], [vx vy Σtt, σ²+vy²Σtt, vyΣtt], [vxΣtt, vyΣtt, Σtt]] です。σ と σt を exp で正に保つので、常に正定値になります。

起動するとまず、3粒×8個のパラメータの勾配について、式で求めた値と有限差分で求めた値が一致するかを検査します。

## 実行結果

出力は [ch09_tiny4d.out.txt](../ch09_tiny4d.out.txt) と同じになります。

- 時空間の相関を学習した場合、評価15枚のPSNRは21.47dBです。動く粒の速度は横0.7015、縦0.0943画素/フレーム（正解は0.7、0.1）になります。
- Σxt = Σyt = 0 に固定した場合、PSNRは18.70dBです。
- 現れて消える粒は、どちらの場合も μt が約15.0、√Σtt が約4.04フレーム（正解は15、3.5）になります。

`ch09_tiny4d.json` には、評価15枚の正解の画像、両条件の描画結果、粒の共分散の成分が保存されます。本文の二つのGIF（箱の中の3粒、評価15時刻の比較）は、このJSONの値から作っています。
